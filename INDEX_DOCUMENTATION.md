## 🎓 GLOSSAIRE

### Termes Techniques

**App Router**  
Architecture de Next.js 13+ utilisant le dossier `app/` pour le routing

**Server Components**  
Composants React rendus côté serveur (par défaut dans Next.js 13+)

**Client Components**  
Composants avec `"use client"` rendus côté client (interactivité)

**Framer Motion**  
Bibliothèque d'animations React

**Tailwind CSS**  
Framework CSS utility-first

**OG (Open Graph)**  
Protocole pour le partage sur réseaux sociaux (Facebook, LinkedIn)

### Termes Métier

**TNS (Travailleur Non-Salarié)**  
Indépendant, auto-entrepreneur, profession libérale

**RC Pro (Responsabilité Civile Professionnelle)**  
Assurance couvrant les dommages causés dans l'exercice professionnel

**PER (Plan Épargne Retraite)**  
Produit d'épargne pour préparer la retraite avec avantage fiscal

**Madelin**  
Contrat de prévoyance/retraite pour TNS avec déduction fiscale

**ORIAS**  
Registre unique des intermédiaires en assurance
